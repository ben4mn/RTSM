## Scope and limits

Lobby/map/start, keyboard checks, sampled construction and results/menu returns use actual browser input. Most sustained gameplay uses a disclosed test-only wrapper on each real browser WebSocket to issue ordinary paid commands, with monotonic sequence normalization. It does not grant resources, mutate replicas, change simulation speed or force a result. Agreement compares authority packets received by the clients and rendered/operator observations; it does not inspect browser replica internals. House destruction is demolition coverage, not an enemy-building kill. No second computer, physical phone, or Web performance certification is claimed.

The broad match's late authority simulation slowed relative to wall time; its final server log reports a recent headless loop rate of 4 FPS, not browser rendering FPS. Its last 100 game seconds took about 175 wall seconds. One late point sample is 99.57% of one CPU and 129.1 MiB/768 MiB. These are observations, not an isolated benchmark or a diagnosis. The run completes and stays synchronized, but this deployment does not resolve late-game server performance.
