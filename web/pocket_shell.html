ON YOUR HOME SCREEN

Ready when you are.

Add Pocket Kingdoms to your Home Screen for its own app window, without the browser bars.

Play in landscape. Tap to select, drag to pan and pinch to zoom. Solo works offline once the complete game is saved; Online 1v1 needs a connection. You can play here without installing.

  1. Open this page in Safari.
  2. Open Share (inside the Page Menu if needed), then choose Add to Home Screen.
  3. Keep Open as Web App on if shown, then tap Add.
  4. Launch the new Pocket Kingdoms icon and turn your device sideways.
  1. Open this page in Chrome or a browser that supports app installation.
  2. Tap Install the game above when the browser offers it. Otherwise open the browser menu and choose Install app or Add to Home screen.
  3. Confirm the installation, then launch the new icon in landscape.
  1. Open this page in Chrome or Edge.
  2. Use the address bar’s install icon or the browser menu’s Install app option when available.
  3. On a Mac with Safari, use File → Add to Dock if available. You can also keep playing in your browser.
